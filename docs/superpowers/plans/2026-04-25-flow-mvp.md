# Flow MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement follow-up tasks. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a clean monorepo **Flow** with FastAPI + LangGraph (deer-flow style graph), Postgres/pgvector, JWT auth, SSE executions, knowledge RAG, preferences + agent memory, feedback + curator proposals, and a Next.js + shadcn UI with branded logo.

**Architecture:** `services/api/flow/` follows light DDD (infrastructure graph + persistence + HTTP). LangGraph uses **AsyncPostgresSaver** and a **planner → worker → synthesizer** pipeline. Frontend uses **App Router**, **shadcn**, dark theme, **EventSource** for streams with `access_token` query (MVP; replace with cookies or short-lived SSE tokens for production).

**Tech Stack:** Python 3.12 · FastAPI · asyncpg · LangGraph · langgraph-checkpoint-postgres · Next.js 16 · shadcn/ui · Docker Compose · Railway.toml
